# hotdiggity-token-submission

Token submission assets and metadata for integrating the HOTDIGGITY token across wallet and analytics platforms.

## Files

| File | Purpose |
|------|---------|
| `DEXTools` | Token info for DEXTools listing |
| `MetaMask` | Token metadata for MetaMask custom token import |
| `TrustWallet` | Token assets for TrustWallet token list |
